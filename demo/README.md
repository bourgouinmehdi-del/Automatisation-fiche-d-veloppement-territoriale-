# Démo — Compiègne (Oise, 60200)

Fichiers produits par `npm run generate -- 60200 --out demo` le 10 octobre 2026.

**Important** : cette génération a eu lieu dans un environnement sans accès aux API publiques. La fiche ne contient donc que les données **réelles** du référentiel embarqué (identité administrative, population légale 2023, intercommunalité et ses 22 communes, rang démographique, communes de taille comparable) et la carte nationale ; toutes les autres sources apparaissent en échec dans le journal de collecte, et les rubriques correspondantes sont signalées comme manquantes. Aucune valeur n'a été complétée.

Pour obtenir la fiche complète, relancer la même commande sur une machine ayant accès à Internet (voir README, section Réseau).
